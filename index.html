1. Technical SEO
Mục tiêu: Đảm bảo bọ tìm kiếm thu thập & lập chỉ mục website chuẩn xác, tối ưu trải nghiệm người dùng kỹ thuật.
Hạng mục triển khai then chốt:
  • Tốc độ tải trang & Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1).
  • Cấu trúc URL logic, sitemap.xml, robots.txt, mã phản hồi (301, 404).
  • Giao diện chuẩn Mobile-First.
  • Dữ liệu có cấu trúc (Schema Markup: Organization, LocalBusiness, Product/Service, FAQ).
Audit Chuẩn W3C
📑
2. On-page SEO
Mục tiêu: Tối ưu hóa nội dung và cấu trúc từng trang theo đúng ý định tìm kiếm (Search Intent) của khách hàng.
Hạng mục triển khai then chốt:
  • Tối ưu bộ thẻ Meta (Title chứa từ khóa chính, Meta Description kích thích CTR).
  • Phân cấp cấu trúc thẻ tiêu đề (H1 duy nhất, H2, H3 mạch lạc).
  • Tối ưu hình ảnh (Alt text mô tả, nén chuẩn WebP thế hệ mới).
  • Điều hướng liên kết nội bộ (Internal Link) theo mô hình Topic Cluster (Cụm chủ đề).
Cụm Topic Cluster
✍️
3. Content SEO
Mục tiêu: Thể hiện chuyên môn sâu, giải quyết "nỗi đau" của khách hàng và dẫn dắt phễu bán hàng hiệu quả.
Hạng mục triển khai then chốt:
  • Nghiên cứu từ khóa phân tầng: Informational (Nhận biết), Commercial (Cân nhắc), Transactional (Hành động).
  • Xây dựng Case Studies, Whitepapers, báo cáo phân tích ngành B2B.
  • Đáp ứng chuẩn E-E-A-T (Kinh nghiệm - Chuyên môn - Thẩm quyền - Đáng tin cậy) với hồ sơ tác giả rõ ràng.
Chuẩn E-E-A-T
🌐
4. Off-page SEO
Mục tiêu: Gia tăng độ uy tín và thẩm quyền của tên miền (Domain Authority) thông qua các tín hiệu bên ngoài.
Hạng mục triển khai then chốt:
  • Xây dựng Backlink chất lượng cao từ báo chí chính thống, trang tin ngành và đối tác chiến lược.
  • Tối ưu Google Business Profile (SEO Local) cho các địa chỉ văn phòng và chi nhánh đại diện.
  • Quản trị danh tiếng thương hiệu (Brand Mentions, trích dẫn báo chí, đánh giá từ khách hàng).

Tối Ưu Bố Cục Tác Động Vào Hành Vi Người Dùng

Khi xây dựng website thương mại và chuyển đổi, bố cục không chỉ đơn thuần là việc xếp hàng các ô HTML mà là **khoa học dẫn dắt hành vi nhận thức**:

1. Quy Tắc Thị Giác F-Pattern & Z-Pattern

Mắt người đọc quét từ Trái sang Phải, Từ Trên xuống Dưới. Việc đặt Logo góc trái, CTA quan trọng góc phải đỉnh trang và Nút Đặt Hàng chính tại điểm kết thúc giúp tăng 35% tỷ lệ click.

2. Nguyên Lý Mỏ Neo Giá (Anchoring Effect)

Bộ não lấy con số đầu tiên nhìn thấy (Giá gốc gạch ngang) làm tiêu chuẩn đánh giá. Mức giá khuyến mãi phía sau lập tức trở nên vô cùng hấp dẫn trong cảm nhận người tiêu dùng.

3. Tâm Lý Né Tránh Mất Mát & FOMO

Con người sợ bị mất đi cơ hội hời hơn là mong muốn nhận thêm phần thưởng. Thông báo khan hiếm số lượng ("Còn 3 suất") giải quyết triệt để tâm lý trì hoãn mua hàng.

4. Giảm Ma Sát Nhận Thức (Cognitive Load)

Quá nhiều lựa chọn khiến não bộ quá tải và quyết định rời đi. Việc giới hạn 3-4 món nổi bật kèm Combo đóng gói sẵn giúp quyết định mua sắm diễn ra tức thì.

Tích Hợp & Hướng Dẫn Sử Dụng GSAP (GreenSock Animation)

GSAP là thư viện tạo hiệu ứng chuyển động chuyên nghiệp hàng đầu thế giới. Hệ thống đã được tích hợp sẵn GSAP v3 & ScrollTrigger.

1. gsap.to() / gsap.from()

Dịch chuyển, xoay, biến đổi opacity mượt mà.

2. gsap.timeline()

Chuỗi chuyển động nối tiếp theo thứ tự không cần callback.

3. ScrollTrigger Plugin

Kích hoạt animation khi lướt chuột đến đúng vị trí khối.

GSAP 3 Quick Reference & Code Usage Guide
// 1. Khai báo GSAP trong mã JavaScript (đã tích hợp trong js/main.js): gsap.registerPlugin(ScrollTrigger); // 2. Chuyển động cơ bản đến trạng thái đích (gsap.to): gsap.to(".element", { x: 100, opacity: 1, duration: 1, ease: "power2.out" }); // 3. Chuyển động bắt đầu từ trạng thái ẩn (gsap.from): gsap.from(".block", { y: 50, opacity: 0, duration: 0.8, stagger: 0.15 }); // 4. Chuỗi chuyển động Timeline nối tiếp: const tl = gsap.timeline({ defaults: { ease: "power3.out" } }); tl.from(".hero-title", { y: -30, opacity: 0, duration: 0.6 }) .from(".hero-desc", { y: 20, opacity: 0, duration: 0.5 }, "-=0.3") .from(".hero-btn", { scale: 0.8, opacity: 0, duration: 0.4 }); // 5. Hiệu ứng cuộn lướt trang (ScrollTrigger): gsap.from(".scroll-target", { scrollTrigger: { trigger: ".scroll-target", start: "top 80%", toggleActions: "play none none none" }, y: 40, opacity: 0, duration: 0.8 });
