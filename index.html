Khung Dựng Website Chuẩn Hóa & Hệ Thống Kiến Thức Frontend

Bộ khung hoàn chỉnh cho mọi dự án Website cơ bản. Xây dựng bằng **HTML5 Semantic**, **Modern Vanilla CSS** (CSS Variables, Flexbox/Grid, Dark Mode) và **JavaScript Clean Architecture**.

Ưu Điểm Của Bộ Framework

Thiết kế tinh gọn, hiệu năng cao và dễ dàng tùy biến cho mọi loại dự án.

🎨

Modern Design Tokens

Hệ thống biến CSS (Variables) quản lý màu sắc HSL, font chữ, khoảng cách và hiệu ứng tại một nơi duy nhất. Đổi màu giao diện tức thì!

🌗

Dark & Light Mode

Hỗ trợ chuyển đổi giao diện Sáng/Tối linh hoạt, tự động nhận diện hệ điều hành và lưu trạng thái người dùng vào LocalStorage.

📐

Responsive & Grid System

Xây dựng theo tư duy Mobile-First kết hợp Flexbox và CSS Grid, đảm bảo website của bạn hiển thị sắc nét trên mọi thiết bị.

Các Khái Niệm Cần Nắm Rõ

Chi tiết đầy đủ được hệ thống hóa trong tài liệu README.md đi kèm.

1. CSS Box Model & Positioning

Nắm rõ cách tính toán thể tích phần tử với box-sizing: border-box và điều khiển vị trí chính xác bằng relative, absolute, fixed, sticky.

2. HTML5 Semantic & SEO

Sử dụng đúng các thẻ ngữ nghĩa <header>, <main>, <section> kết hợp meta tags OpenGraph để tối ưu điểm SEO trên Google Search.

3. Modern Visual Aesthetics

Áp dụng hiệu ứng Glassmorphism (làm mờ nền), gradients hiện đại, bo góc đồng bộ và hiệu ứng micro-animations tăng trải nghiệm người dùng.

4. Quy Trình Phát Triển Web

Từ ý tưởng Wireframe, thiết kế UI/UX trên Figma, viết mã HTML/CSS/JS cho đến kiểm thử đa trình duyệt và deploy lên hosting.

Hướng Dẫn Khởi Tạo Dự Án Mới

Tái sử dụng bộ Framework này chỉ trong 3 bước đơn giản.

Bước 1

Copy Thư Mục

Sao chép toàn bộ thư mục framework này và đổi tên thành tên dự án mới của bạn.

Bước 2

Chỉnh `variables.css`

Chỉnh sửa các giá trị màu sắc, phông chữ trong file css/variables.css phù hợp với thương hiệu mới.

Bước 3

Viết Code & Run

Thêm nội dung HTML vào index.html, mở với Live Server và sẵn sàng trình diễn!
